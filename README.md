# Night Case Calendar 5.0

Offline-Schulplaner, Kalender und Aufgaben-App als PWA im ruhigen Dark Student Command Center Look.

## Neue UX in Version 5.0

- klarere visuelle Hierarchie
- neue Heute-Seite mit Fokus auf den nächsten Termin
- kompakter Header
- Desktop: nur Sidebar
- Mobile/iPhone: reduzierte Bottom-Navigation mit 5 Punkten
- Mehr-Menü für Notizen, Statistiken und Einstellungen
- Kalender mit ausgewähltem Tag und klarer Tagesliste
- Aufgaben und Notizen öffnen als Modal statt dauerhaft Platz zu belegen
- ruhigeres Night-Case-Design mit weniger Glanz, weniger Rahmen und besserer Lesbarkeit
- verbesserter iPhone/PWA-Modus

## Start

1. ZIP entpacken.
2. `index.html` im Browser öffnen.
3. Für iPhone-PWA über HTTPS hosten, dann in Safari öffnen und zum Home-Bildschirm hinzufügen.
